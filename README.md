# 블로그 NAVI v1.4.4 — 의미 기반 대조·수치 엄격검증·최종 인증

## 주요 변경 사항

1. **의미 기반 주장 비교**: 단어와 문장이 정확히 일치하지 않아도 같은 의미면 AI는 `일치` 판정할 수 있도록 지시합니다. 이 판정은 보조 판단입니다.
2. **수치 엄격 검증**: AI 교정안과 담당자의 최종 원고에 있는 `%`, 인원, 등급, 학년도 등의 수치를 등록 문서의 추출 텍스트와 정확히 대조합니다. 확인되지 않은 수치는 인증 전에 막고 근거 문서 보완 또는 표현 수정 안내를 합니다. 단, 문서에 동일 수치가 다른 맥락으로 쓰인 경우까지 자동 판별하지 못할 수 있으므로 담당자의 검토가 필요합니다.
3. **AI 수정 강제 규칙**: 오류는 근거자료로 뒷받침되는 정확한 표현으로 교체하고, 수정 근거가 없는 주장은 원고에서 삭제하도록 요청합니다. 자료에 없는 사실을 지어내지 않습니다.
4. **수정 색상 비교**: AI 교정 제안 화면에서 삭제·대체된 부분은 빨간 취소선, 새로 추가한 부분은 초록 강조로 표시합니다.
5. **직접 수정·최종 인증**: 교정본을 읽고 직접 편집한 뒤 사실 확인 체크박스와 `최종 인증 · 승인 완료` 버튼으로 승인합니다. 기존의 원문 인용 글자 단위 일치·반복 검증 차단은 마지막 인증에 적용하지 않습니다. 단, 공식 문서와 숫자의 형식적 대응은 검사합니다.
6. **이력 저장**: 승인 시 `approval_audit` 테이블에 승인 시각·원고 해시·근거 해시·검증 보고서 ID·선택 기록을 저장합니다. 전체 ZIP 백업에도 포함됩니다.

## 기존 앱 업데이트

1. Streamlit 앱의 **설정·백업**에서 기존 자료 ZIP을 다운로드하십시오.
2. 이 폴더의 `app.py`를 GitHub 저장소의 기존 파일과 교체하고 Commit changes 하십시오.
3. `requirements.txt`는 기존과 동일합니다. 기존 `BLOG_NAVI_PASSWORD`, `OPENAI_API_KEY`도 변경하지 않습니다.
4. Streamlit을 새로고침하여 왼쪽 **원고 편집·검수** 메뉴로 들어갑니다.
5. 공식 자료를 1건 이상 등록하고 **AI 검증하고 정확한 내용으로 교정안 만들기**를 누릅니다.
6. 빨간/초록 변경점과 근거 문서를 확인하고 아래의 최종 원고를 추가 편집합니다.
7. 담당자 확인 체크박스를 선택한 후 **최종 인증 · 승인 완료**를 누르면 승인 상태가 됩니다.
8. **예약 발행 지원** 메뉴에서 게시용 파일을 생성하고 실제 블로그 편집기에서 예약 게시를 등록합니다.

## 주의

- 최종 인증은 사용자의 **편집 승인**이며 공식기관 또는 AI의 무오류 보증이 아닙니다.
- 문장의 의미 일치 판정은 AI 보조 판단입니다. `49.9%`와 `49.8%`는 다르게 취급합니다.
- 숫자 검사는 원문 텍스트에 수치가 존재하는지 확인하는 기본 검증으로, 같은 숫자의 문맥이 적절한지까지 기계적으로 보장하지 않습니다.
- 등록 PDF에서 추출된 텍스트가 짤리거나 스캔 PDF면 수치 검증이 막힐 수 있습니다.
- Streamlit Community Cloud 로컬 SQLite는 영구 보존을 보장하지 않습니다. 기존과 같이 백업을 진행하세요.
- 공식 URL에서 자동 수집된 자료는 사용자가 발행기관·학년도·원문을 확인해야 합니다.
