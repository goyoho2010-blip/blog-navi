# 블로그 NAVI v1.1 — 천명의선택

기존 v1.0의 콘텐츠 생성·편집·검수·예약 발행 지원·성과 분석을 유지하면서, **공식 문서 PDF/TXT 업로드와 AI 원문 대조**를 추가했습니다.

## Streamlit Cloud 업데이트

1. 이 ZIP을 풀고 GitHub의 기존 블로그 NAVI 저장소 **루트**에 `app.py`, `requirements.txt`를 업로드하여 기존 파일을 교체합니다. `README.md` 교체도 권장합니다.
2. Streamlit Cloud는 GitHub 커밋 후 보통 재배포합니다. 재시작한 뒤 화면에 `v1.1` 및 사이드바 `공식자료·근거 검증` 메뉴가 보이는지 확인합니다.
3. 기존 Secrets는 그대로 사용합니다. `BLOG_NAVI_PASSWORD`와 `OPENAI_API_KEY`가 필요하며 키 값은 GitHub에 올리지 마세요.
4. 설치 라이브러리가 추가되었습니다: `PyMuPDF>=1.24,<2`.

## 사용 순서

1. **콘텐츠 기획·생성**에서 AI 초안을 작성·저장합니다.
2. **공식자료·근거 검증**에서 해당 원고를 선택합니다.
3. 교육부·대교협·대학 입학처에서 내려받은 공식 PDF(텍스트형) 또는 UTF-8 TXT를 업로드하고 발행기관·문서명·공식 URL·확인일을 직접 기록합니다.
4. **원고와 문서 대조 · 검증 보고서 작성**을 클릭합니다. 주장별 일치/불일치/근거부족, 원문 인용 및 페이지, 수정 권고와 수정 초안을 생성합니다. 원본 원고는 자동으로 덮어쓰지 않습니다.
5. 수정 초안을 반영했다면 **반드시 다시 AI 대조를 실행**합니다. 원고/근거 문서가 바뀐 경우 이전 보고서는 승인에 사용할 수 없습니다.
6. **원고 편집·검수**에서 사람이 공식 원문을 직접 확인하여 `수동 사실확인 기록`을 입력하고, 모든 `차단` 항목을 해결한 후 `승인`합니다.
7. **예약 발행 지원**에서 HTML/TXT/ICS 파일을 출력하고 네이버/티스토리 편집기에서 **직접** 예약 등록합니다.

## 한계 및 주의

- **AI 검증은 원문 대조 보조 기능이며 공식 문서의 진위를 자동으로 판별하지 않습니다.** 업로드 문서의 출처·적용 학년도·현행성은 담당자가 확인해야 합니다.
- 대용량 PDF에서 **최대 4개 문서 각각 앞부분 18,000자**만 AI 대조에 전송합니다. 보고서에서 누락된 내용은 '근거부족'으로 처리할 수 있습니다. PDF에서 텍스트는 전체 추출해 저장하나, 모델 입력에는 비용 제한이 있습니다.
- 12MB/120페이지 이하 PDF 또는 UTF-8 TXT 파일만 지원합니다. **이미지 스캔 PDF는 OCR을 지원하지 않습니다.** 텍스트 추출이 100자 미만이면 오류가 납니다.
- 원고와 근거자료는 기본적으로 로컬 SQLite에 저장됩니다. **Streamlit Community Cloud에서는 재배포·재시작 시 로컬 데이터 소실 가능성**이 있습니다. `설정·백업`에서 ZIP을 자주 내려받으세요. ZIP에 근거 문서의 **추출 텍스트**와 리포트가 포함되므로 민감정보를 업로드하지 마세요. 현재 복원은 원고 목록만 지원합니다.
- 문서 텍스트가 AI API로 전송됩니다. 학생·학부모 개인정보, 공개되지 않은 입시자료 등은 업로드하지 마세요.
- 기존 글쓰기 공식 API가 없어 네이버/티스토리 자동 게시 기능은 지원하지 않습니다.
- 기존 v1.0의 승인된 글이라도, v1.1에서 새롭게 승인 또는 재검수할 때는 근거자료 업로드와 대조 보고서가 필요합니다.

## 로컬 설치

```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit Secrets 예:

```toml
BLOG_NAVI_PASSWORD = "본인 관리자 암호"
OPENAI_API_KEY = "본인 API 키"
```
