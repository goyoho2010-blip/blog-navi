# 블로그 NAVI v1.4.5 — 직접 링크·문장 비교·수치 최종 확인

## 개선 사항

1. **AI 검색 링크 선택 방식 유지**: `공식 출처 자동 검색` 메뉴의 AI 검색 → 결과 선택 → 원고 등록 기능은 그대로입니다.
2. **사용자가 직접 찾은 공식 URL**: 같은 메뉴 하단 `직접 찾은 공식 링크 등록 · 원문 정리`에서 원고, https 공식 URL, 자료명, 발행기관, 확인일을 입력해 **원문을 실제 추출**하고 등록할 수 있습니다. 이어 `등록된 링크·PDF 원문 AI로 핵심 내용 정리`로 요약합니다. 해당 원고는 `원고 편집·검수`에서 AI 비교·검증 및 교정할 수 있습니다.
3. **이전 문장 vs 수정 문장 나란히 비교**: `원고 편집·검수 → ② 변경된 문장 색상 비교`에서 빨간쪽은 기존, 초록쪽은 AI 수정 결과입니다. 추가로 단어 단위 변경 미리보기를 접어 볼 수 있습니다.
4. **최종 편집에서 추가한 수치만 확인**: AI 수정본을 사용자가 마지막에 수정하여 `49.9%` 등 새 수치가 생기면 `최종 편집에서 추가한 수치 확인` 창이 나타납니다. 사용자가 값을 검토하고 `수치 확인 · 최종 인증 완료`를 누르면 **그 수치가 등록된 근거 PDF에 없다는 이유로 승인이 막히지 않습니다.** 추가 수치가 없다면 최종 인증 버튼만으로 완료됩니다.
5. **승인 이력**: 최종 원고와 담당자 확인 기록을 `approval_audit`에 남기며, 인증 후 상태는 `승인`으로 변경됩니다.

## 사용 순서

1. 기존 앱 `설정·백업`에서 백업 ZIP을 다운로드하세요. 현재 편집하고 저장하지 않은 원고는 별도 복사해 보관하세요.
2. 압축 파일의 `app.py`만 기존 GitHub 저장소의 `app.py`로 교체하고 Commit 하세요. `requirements.txt`는 변경되지 않았습니다.
3. Streamlit에서 새로고침(`Ctrl + Shift + R`)하세요. 기존 비밀번호·API 키는 그대로 사용합니다.
4. `공식 출처 자동 검색`에서 AI 검색 결과를 선택하거나, 하단의 직접 URL 입력을 사용하세요. 링크는 실제 공식 사이트의 HTTPS 주소만 허용합니다. 원문이 HTML/PDF가 아니거나 사이트가 접근을 막으면 기존 수동 PDF 업로드를 이용하세요.
5. `원고 편집·검수`에서 AI 검증과 교정안을 생성하세요. 전후 문장 비교표를 확인하고 최종 원고를 편집하세요.
6. **최종 인증 · 승인 완료**를 누릅니다. 새 수치를 직접 넣었다면 값들을 확인하는 단계가 한 번 더 나타납니다. `수치 확인 · 최종 인증 완료`를 누르면 끝납니다.
7. `예약 발행 지원`에서 승인된 원고를 내보내세요. 블로그 자동 게시는 지원하지 않습니다.

## 제한 사항 및 보안

- 직접 URL 기능은 공식 도메인(`.go.kr`, `.ac.kr`, `kcue.or.kr`, `adiga.kr` 등)만 수집합니다. 임의 링크 자동 접근을 허용하지 않으며, 리다이렉션은 자동으로 따라가지 않습니다.
- 페이지별 PDF 자동 첨부 탐색 및 기존 PDF 업로드 기능을 유지했습니다.
- 원문 요약과 AI 검증은 긴 자료 일부(최대 4건, 건당 일정 길이)만 사용할 수 있으며, AI가 수치·맥락을 오판할 수 있습니다.
- **사용자 인증은 실무 승인 기록이며 외부 기관의 사실 검증을 의미하지 않습니다.** 검증하지 못한 새 수치를 승인해도 자동으로 '공식자료 검증됨'으로 표시해서는 안 됩니다.
- 최종 인증 후 원고·출처가 변경되면 다시 검토해야 합니다.
- Streamlit Community Cloud에서 로컬 SQLite의 데이터 영구 보존이 보장되지 않으니 백업 및 외부 DB 전환을 권장합니다.

## 확인한 테스트 범위

- Python 코드 문법 컴파일
- 편집자가 추가한 수치만 탐지하는 함수 단위 테스트 (`49.9%`→`49.8%` 검출)
- 문장별 수정 전후 비교 생성 함수 단위 테스트
- ZIP 파일 생성·내용 확인

실제 Streamlit 클라우드 UI와 OpenAI API 유료 호출 통합 검증은 배포 환경에서 별도로 확인해야 합니다.
