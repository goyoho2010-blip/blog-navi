# 블로그 NAVI v1.2.1 — 공식 출처 자동 검색 + 근거 기반 AI 원고

천명의선택 입시연구소 | Streamlit 웹앱

## v1.2.1 추가 기능

- **공식 출처 자동 검색:** OpenAI Responses API `web_search`를 사용하여 교육부·정부·대교협·평가원·대학 공식 도메인(`go.kr`, `ac.kr`, `moe.go.kr`, `kcue.or.kr`, `adiga.kr`, `kice.re.kr`)의 검색 출처 URL 목록과 요약을 가져옵니다. 검색에는 별도의 API 요금이 발생할 수 있습니다.
- **출처 등록:** 검색한 공식 URL을 직접 확인한 뒤 선택한 원고에 기록합니다. 실제 확인 전에는 검증된 것으로 간주하지 않습니다.
- **공식 URL 원문 읽기(시험):** 허용된 HTTPS 공식 도메인의 PDF 또는 HTML을 가져와 텍스트를 추출하고 원고에 근거자료로 등록합니다. 리다이렉트·대용량 파일·본문 추출 불가 페이지는 차단하며, PDF 직접 업로드로 대체할 수 있습니다.
- **근거 기반 AI 원고 재작성:** 등록 근거자료 최대 4개에서 각 앞부분 18,000자를 AI에 전달하여 초안을 작성합니다. **전체 원문을 읽은 것처럼 주장할 수 없습니다.** 사용자가 명시적으로 반영한 경우에만 기존 원고를 덮어씁니다.
- **AI 근거 대조:** 주장별 일치/불일치/근거부족, 증거 인용, 페이지, 수정 제안을 생성합니다. 원고 변경 또는 근거 변경 시 이전 검증은 무효 처리됩니다.
- **승인 절차:** 수동 사실확인 기록, 근거자료, 검증 보고서, 핵심 차단항목 해소가 필요합니다. 자동 사실 검증이나 자동 게시는 제공하지 않습니다.

## GitHub/Streamlit Cloud 업데이트

1. 앱의 **설정·백업** 메뉴에서 `전체 JSON 백업 ZIP`을 먼저 다운로드합니다. 이 ZIP은 추출된 문서 텍스트를 포함하므로 안전하게 보관하십시오.
2. 이 패키지의 `app.py`, `requirements.txt`, `README.md`를 GitHub의 기존 blog-navi 저장소 **루트**에 업로드하여 파일을 교체합니다.
3. GitHub에서 Commit changes 후 Streamlit 앱을 재시작하거나 새로고침합니다.
4. 사이드바에 **공식 출처 자동 검색** 메뉴가 나타나는지 확인합니다.
5. Streamlit Secrets 설정은 기존대로 유지합니다.

```toml
BLOG_NAVI_PASSWORD = "본인이정한관리자비밀번호"
OPENAI_API_KEY = "본인이발급한실제API키"
```

> 주의: API 키·관리자 비밀번호를 GitHub에 올리지 마십시오. 관리자 비밀번호가 없으면 v1.2 앱은 실행을 차단합니다.

## 첫 번째 실제 사용 흐름

1. **콘텐츠 기획·생성** 메뉴에서 먼저 제목과 주제를 정하고 원고를 저장합니다.
2. **공식 출처 자동 검색** 메뉴에서 `2028학년도 대학입시제도 개편 확정안 교육부`를 검색합니다.
3. 검색된 URL을 `원문 열어 확인` 버튼으로 확인한 뒤 관련 출처를 선택하고 원고에 기록합니다.
4. 검색 출처 한 개를 선택하면 **선택 URL 원문 읽기 · 근거자료 등록**을 시험할 수 있습니다. 홈페이지 링크가 공지사항 목록이고 본문이 없다면 해당 공식 문서 PDF를 내려받아 직접 업로드하십시오.
5. **공식자료·근거 검증** 메뉴에서 해당 원고를 고릅니다. 등록 문서가 있다면 **등록 문서로 AI 원고 재작성**을 눌러 초안을 생성합니다. 내용을 점검한 뒤 명시적으로 반영합니다.
6. 같은 메뉴에서 **원고와 문서 대조 · 검증 보고서 작성**을 실행합니다. 근거 부족·불일치 항목을 정정한 뒤 다시 검증합니다.
7. **원고 편집·검수**에서 수동 사실확인 기록을 작성하고 승인합니다. **예약 발행 지원**에서 게시용 HTML/TXT 파일과 캘린더를 내려받아 네이버/티스토리 편집기에서 직접 예약 발행합니다.

## 운영상의 제한

- 검색 결과 URL은 **후보 출처**입니다. 도메인 제한 검색으로 공식 사이트가 아닌 URL을 줄일 수 있지만, 페이지가 진짜 해당 학년도의 최종 모집요강인지 자동으로 입증하지는 않습니다.
- 원문 읽기는 PDF/HTML 텍스트에 한정됩니다. 이미지 스캔 PDF는 OCR 미지원입니다. PDF 12MB/120쪽 제한, 응답 12MB 제한이 있습니다. 화면의 안내에 따라 직접 업로드할 수 있습니다.
- 대용량 근거자료는 AI 입력 비용을 제한하기 위해 4개 문서, 각 앞부분 18,000자만 전송합니다. 특정 전형 정보를 찾지 못하면 근거부족으로 처리될 수 있습니다.
- Streamlit Community Cloud의 **로컬 SQLite는 영속 저장소가 아닙니다**. 앱 재배포/재시작 때 원고·근거자료가 사라질 수 있습니다. 정기 ZIP 백업을 권장하며 장기 운영에는 PostgreSQL 등 외부 DB 연결이 필요합니다.
- **백업 ZIP은 원고/성과/근거자료/검증 리포트를 포함하지만, 복원 UI는 posts.json 원고만 병합**합니다. 복원한 원고는 반드시 다시 검증해야 합니다. 근거자료 전체 복원은 향후 버전에서 지원합니다.
- 검색 웹 검색, 근거기반 작성, 근거 대조 기능은 OpenAI API를 호출하며, 별도 사용료가 발생합니다.
- 공식 블로그 글쓰기 API를 통한 자동 발행 기능은 제공하지 않습니다. 예약 발행은 각 플랫폼에서 수동 확정합니다.

## v1.2.1 오류 수정 (API 400 filters)

- `gpt-4.1-mini`에서 `filters`를 전송하지 않도록 수정했습니다. 공식 사이트 위주의 검색어를 사용하고 **검색 결과의 URL은 허용된 공식 도메인만 표시**합니다.
- 다른 모델에서 `filters` 옵션이 거절되면 해당 오류에 한해 옵션 없이 1회 재시도합니다.
- 검색 결과의 요약은 공식 출처로 검증된 내용이 아니며, 원문 확인과 AI 근거 대조가 여전히 필요합니다.
- 기존 Secrets, 데이터베이스 구조, 발행 기능은 유지합니다. 배포 전 JSON 백업을 권장합니다.
