# 블로그 NAVI v1.4.1 — 원고 문제 위치 표시

## 적용
1. 기존 앱의 설정·백업에서 원고 데이터를 백업합니다.
2. GitHub의 `app.py`를 이번 압축 파일의 `app.py`로 교체합니다. `requirements.txt`는 기존 파일을 유지해도 됩니다.
3. Commit 후 Streamlit에서 Ctrl+Shift+R로 새로고침합니다.
4. 원고 편집·검수에서 **원고 문제 위치 표시 · 수정 안내**를 확인합니다.

## 표시 원칙
- 노란색 강조: 실제 본문에서 확인된 문자열만 표시합니다.
- 줄 번호와 수정 권고: 강조 위치를 원고 편집란에서 찾아 수정하는 데 사용합니다.
- AI 검증 보고서의 주장 원문이 본문에 정확히 나타나지 않으면 위치를 추측하지 않습니다.
- 출처 URL·확인일·수동 사실확인 기록·원문 검증은 원고 문장과 별개의 메타데이터 항목입니다.
- 수정 후 **검수 후 저장** → 공식자료·근거 검증에서 **AI 재검증** → 승인 순서로 진행합니다.

## 주의
이 기능은 편집기 내부의 인라인 하이라이트가 아니라 편집기 아래의 **원고 강조 미리보기**입니다. Streamlit 기본 text_area에서는 특정 부분만 색칠할 수 없습니다. 자동 발견은 완전한 사실검증이 아니며 공식 원문 대조가 필요합니다.
